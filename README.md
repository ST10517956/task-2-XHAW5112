# Pawsitive Pet Academy — Mobile App (Task 2, Phase 2)

Kotlin / Android Studio app matching the high-fidelity wireframes and the
website. Bottom navigation: Home, Overview, Fees, Contact. About Us opens
from the logo icon in the top bar.

## How to open

1. Open Android Studio → **Open** → select this `PawsitivePetAcademy` folder.
2. Let Gradle sync (first sync downloads dependencies, needs internet).
3. Run on an emulator or device (minSdk 24 / Android 7.0+).

## What's built

- All 12 screens from the app wireframes: Home, About Us, Overview, the 7
  individual course pages, Calculate Fees, Contact Us.
- Bottom navigation bar, matching the wireframes.
- Fee calculator with the same discount logic as the website (2 courses 5%,
  3 courses 10%, 4+ courses 15%).
- Contact form with basic validation (name, valid email, message required).
- Brand colours (navy `#1A365D`, teal `#52796F`, coral `#E9967A`,
  off-white `#F8F9FA`) applied throughout.
- Real course photos (same images used on the website) on Home, Overview,
  each course detail page, and the About Us team photo.
